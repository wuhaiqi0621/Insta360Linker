## Step 173 - 连接时读取相机当前模式

完整状态请求：

```text
command 0x0008
request id 0x80000003
```

相机在 `15:49:05.969` 返回 `1,171-byte` internal payload。
去掉 9 字节 internal header 后，响应 body 顶层 protobuf field 2
是一段长度分隔的完整状态消息。

该状态消息偏移 `607` 处：

```text
c0 02 00 c8 02 64
```

protobuf 解码：

```text
c0 02 = field 40, wire type 0
00    = field 40 value 0
c8 02 = field 41, wire type 0
64    = field 41 value 100
```

用户说明连接时相机处于拍照模式，因此这是直接证据：

```text
Photo = field40 0, field41 100
```

已捕获的模式事件使用完全相同的二值对：

```text
Photo event = field1 0, field2 100
Video event = field1 100, field2 0
```

由相同字段结构交叉推断：

```text
Video = field40 100, field41 0
```

实现现在会：

1. 连接后执行完整状态查询。
2. 从响应顶层 field 2 取出嵌套状态消息。
3. 读取 field 40 与 field 41。
4. 将 `(0,100)` 映射为 Photo，将 `(100,0)` 映射为 Video。
5. 无法识别时保持 `None`，前端显示“请选择拍摄模式”，不猜测默认模式。

`camera_control_connect` 原有返回值已经包含 `mode`，因此前端无需新增命令；
连接成功后会直接选中相机实际的“拍照”或“录像”分段按钮。
